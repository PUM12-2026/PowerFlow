PowerFlow
=========

PowerFlow is a `power flow/load flow <https://en.wikipedia.org/wiki/Power-flow_study>`_
simulation tool that can be used to calculate voltages, gradients and cable paramaters in electrical grids given known
power consumptions. PowerFlow is written in C++ for fast performance and comes with Matlab
and Python bindings for use within Matlab and Python scripts.
